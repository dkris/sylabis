03

Shared foundation

The invariants live here — one model gate, one prompt set, one frontmatter writer.

model gate

llm.py

The only place model calls happen. .call() mocks from fixtures; .chat() is the live agent loop — no mock, by design.

prompts

prompts.py

Eight system prompts as constants. The pipeline stages are their prompts — versioned like code.

credential

okf.py

The only frontmatter writer. The bundle on disk is the credential; okf.yaml inventories every doc.

ledger

events.py

Append-only events.jsonl (schema 1). Written from day one as the pathway-graph seed.

sources

verify.py

Checks harvest locators (arXiv · doi.org · HEAD). Flags-and-continues — never blocks a compile.

read & write — the single source of truth
04

On disk — the journey

No database, no cache. journey.py reads the bundles, so it can never disagree with them.

A journey is a home directory of courses. Attach one from anywhere — a local path symlinks, a git URL clones — and its verified knowledge counts the same.

$SYLABIS_HOME/            # default ~/sylabis · override with --home
├── courses/
│   └── <course>/
│       ├── course.yaml           # manifest: milestones, sidequests
│       ├── okf.yaml              # document inventory (the credential)
│       ├── <milestone>/
│       │   ├── LESSON.md          # OKF frontmatter + lesson
│       │   ├── checkpoint.yaml    # rubric, grader mode, misconception
│       │   ├── artifact.md · reflection.md   # the learner's own work
│       │   └── grade.yaml         # tiered result
│       ├── portfolio/             # competency-evidence claims
│       ├── events.jsonl           # append-only ledger
│       └── .github/workflows/grade.yml  # push artifact → CI grades → PR comment
└── knowledge.md              # cross-course map: concept → evidence

Invariants — deliberate, not shortcuts

  • The work is the learner's. The guide never writes an artifact or reflection; submit only verbatim text.
  • Grades come only from the grader. The agent must never predict or promise one.
  • Tiers short-circuit. Overclaiming blocks before quality judgment; explain-back can cap a passing score.
  • actuate() is idempotent. Re-grading never stacks remedials or double-emits events.
  • okf.py is the only frontmatter writer. All document production routes through it.
  • Routes refuse traversal. ../, absolute, and nonexistent paths are turned away.
